## Notes on the AI-generated process

- The dataset, general workflow shape (load → summarize → visualize → cross-validate → evaluate),
  and choice of six classic classifiers (Logistic Regression, LDA, KNN, CART, Naive Bayes, SVM)
  match the manually built Part A submission, since both are working from the same well-known
  "hello world" ML tutorial structure.
- Two small API adjustments were made proactively based on lessons learned while debugging the
  manual notebook in this same course: `LogisticRegression` uses `solver='lbfgs'` (rather than
  `liblinear`, which no longer supports multiclass problems in current scikit-learn), and
  `plt.boxplot()` uses the `tick_labels` argument (rather than the deprecated `labels` argument
  in current matplotlib).
- Final model selected: SVM, evaluated once on the untouched validation split.
